# Academic Project Website Template

A static website template for academic project pages, suitable for conference submissions and anonymous review.

Currently ships as a minimal blank page with a title placeholder. Additional template assets (navigation, carousels, section styles) are kept in `static/` for when you expand the page later.

## Usage

1. Edit the title in `index.html`.
2. Add authors, abstract, sections, images, and videos as needed.
3. Deploy via GitHub Pages (see `.github/workflows/static.yml`).
